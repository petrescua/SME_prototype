# SME_prototype
Final Dissertation Project using python to check Event Logs, Sysmon and PowerShell Script Logging in particular, to check for fileless techniques usage on a Windows device.
This looks at 4 different areas, including what PowerShell commands are ran, if there are any macros on the device, if UAC values have been changed and if any new start up programs have been added.
This repository contains the code before it was made into one single prototype as well, to show changes made.
